# 小游戏合集

一个基于微信小游戏 Canvas 的轻量游戏合集。目前已完成：

- 扫雷三档难度：初级 9 × 9 / 10 雷、中级 12 × 12 / 24 雷、高级 16 × 16 / 50 雷
- 首次点击安全，并自动展开空白区域
- 轻触翻开、长按循环标记旗子 / 问号 / 清除
- 翻格带消散扩散效果，旗子和问号带弹跳效果，踩雷带冲击波
- 长按时显示 3 × 3 放大区域，避免手指遮挡目标格
- 长按后可拖动切换目标格，松手时应用标记
- 点击已打开的数字格，可快速展开周围未标旗格
- 操作视图中棋盘格最小保持 32px，可用四边箭头移动视口，边界处自动隐藏箭头
- 点击缩小可直接查看完整棋盘，全局视图不限制单格尺寸
- 毫秒级计时与本地最佳成绩
- 每个难度独立记录排行榜，每次通关都会新增记录，同一玩家可多次上榜
- 2048：四向滑动、方块位移动画、数字合并、计分、最佳成绩和 2048 胜利挑战
- 塔防：章节地图、第一关晨曦林地、6 波敌人和关卡星级评价
- 塔防支持箭塔、炮塔、法师塔，包含建造、三级升级、出售和金币循环
- 塔防第一关包含普通、快速、护甲和 Boss 敌人，并支持战斗进度存档
- 首页游戏选择与后续游戏占位
- 自动保存当前进度，首页可继续上一次游戏
- 根据手机像素比进行高清 Canvas 渲染

## 源码目录介绍

```
├── audio                                      // 音频资源
├── images                                     // 图片资源
├── js
│   ├── games
│   │   ├── game2048.js                        // 2048 合并规则与状态
│   │   ├── minesweeper.js                     // 扫雷规则与状态
│   │   └── towerDefense.js                    // 塔防关卡、波次与战斗规则
│   ├── ui
│   │   └── draw.js                            // 通用 Canvas 绘制函数
│   ├── main.js                                // 页面、触摸与渲染入口
│   └── render.js                              // Canvas 与安全区初始化
├── .eslintrc.js                               // 代码规范
├── game.js                                    // 游戏逻辑主入口
├── game.json                                  // 游戏运行时配置
├── project.config.json                        // 项目配置
└── project.private.config.json                // 项目个人配置
```
